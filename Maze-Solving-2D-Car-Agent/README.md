# Maze Solving 2D Car Agent

A Python Tkinter-based autonomous 2D car agent that navigates maze environments using LiDAR-style ray sensing, collision avoidance, spatial memory (heatmap), and dead-end recovery.

## Requirements
- Python 3.x
- Standard library only (tkinter, math, time, random, collections)

## Run
```bash
python 2D_CAR.py
```

## Features
- 9 preset mazes
- Custom maze drawing
- 360° LiDAR simulation
- Autonomous navigation
- Radar and cognitive log
